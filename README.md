# Guardián Lessons

Open, bilingual (English / Español) Bitcoin self-custody safety curriculum and a signet scam-scenario library.

## What this is
1. **Curriculum**: short, practical lessons on wallet setup, seed-phrase backup and protection, verifying addresses, receiving money from family abroad, and recognizing common scam scripts.
2. **Scam-scenario library (signet only)**: realistic fake-support chats, fake "recovery services", romance/investment setups, family-emergency impersonation, address poisoning and lookalike wallet sites. Run on Bitcoin signet with test coins, so no real funds are ever at risk. Each scenario ships with an educator guide.

Bitcoin only. No accounts, no tracking, no paywall.

## Status
Early stage: this first commit contains the outline and a sample lesson stub. Everything is built in public.
